HIRYU LINK (link on): message 1 and message 2 bodies
============================================================
Easiest: console > Simulator Grab > Uji sambungan Hiryu (Ops HQ) builds and sends these.
By hand, as Hiryu (the path is public, the secret is POS_SHARED_SECRET of wms-test--dev):
  curl -X POST https://<dev host>/api/hiryu/v1/orders -H 'Content-Type: application/json' \
       -H 'X-Hiryu-Key: <secret>' -d @body.json
Each message_id is used once: sending the same body again returns the first answer.
Change message_id and grab_order_id to send a new order.
